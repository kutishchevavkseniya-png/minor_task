Решение алгоритмической задачи

Задача № 1014

Даны вещественные положительные числа a, b, c, d. Выясните, может ли прямоугольник со сторонами a, b уместиться внутри прямоугольника со сторонами c, d так, чтобы каждая сторона внутреннего прямоугольника была параллельна или перпендикулярна стороне внешнего прямоугольника.

Логика: (a <= c && b <= d) || (b <= c && a <= d).

При отправке условие, числа и результат уходят стороннему сервису httpbin, который показывает полученные поля. Не вводите личные данные.

Введите четыре положительных числа и нажмите «Вычислить».

Как работает решение

  1. Проверяется вариант без поворота: a <= c && b <= d.
  2. Проверяется поворот на 90°: b <= c && a <= d.
  3. Если подходит хотя бы один вариант, прямоугольник помещается.

Знак <= допускает равенство размеров.
