Команды для консоли разработчика

Откройте инструменты разработчика, перейдите на вкладку Console и выполните команды по одной:

document.getElementById('passport-surname').textContent
document.getElementById('passport-name').textContent
document.getElementById('passport-year').textContent

Каждая команда получает текст соответствующего элемента из DOM.

Место для скриншота

После заполнения данных выполните три команды, сделайте скриншот браузера вместе с консолью и сохраните его как images/dom-console.png. Затем добавьте сюда тег: 

<img src="images/dom-console.png" alt="Получение фамилии, имени и года рождения из DOM">

Сейчас картинка намеренно не подключена, чтобы на странице не было битого изображения.
