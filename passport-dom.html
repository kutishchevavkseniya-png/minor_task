Команды для консоли разработчика

Откройте инструменты разработчика, перейдите на вкладку Console и выполните команды по одной:

document.getElementById('passport-surname').textContent
document.getElementById('passport-name').textContent
document.getElementById('passport-year').textContent

Каждая команда получает текст соответствующего элемента из DOM.
