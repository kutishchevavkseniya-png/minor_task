# Leo Wear — учебный сайт магазина одежды для собак
## Как открыть сайт локально

Самый простой способ — открыть файл `index.html` двойным щелчком в браузере.
Для проверки отправки форм нужен интернет: после отправки откроется ответ учебного
сервиса httpbin в новой вкладке.

## Файлы проекта

- `index.html` — главная страница, описание и преимущества;
- `catalog.html` — каталог из трёх товаров;
- `sizes.html` — снятие мерок и таблица размеров;
- `order.html` — учебная форма заказа со всеми типами полей из задания;
- `contacts.html` — форма контактных данных;
- `passport-dom.html` — учебный паспорт и команды чтения DOM;
- `passport-latin.html` — изменение фамилии и имени по клику;
- `algorithm.html` — решение задачи № 1014;
- `raincoat-photo.html` — увеличенное фото дождевика 600 × 400 px;
- `style.css` — общий внешний вид всех страниц;
- `script.js` — обработчики паспорта и алгоритмической задачи;
- `images/` — фотографии, фон таблицы и SVG-логотип;
- `EXPLANATION.md` — объяснение к защите;
- `CHECKLIST.md` — проверка требований преподавателя.
