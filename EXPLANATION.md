# Объяснение проекта для защиты

## Что такое HTML, CSS и JavaScript

- **HTML** задаёт смысл и структуру страницы: заголовки, абзацы, ссылки, изображения,
  таблицу и формы.
- **CSS** отвечает за внешний вид: цвета, размеры, отступы, сетку карточек и адаптацию
  под телефон.
- **JavaScript** добавляет поведение: меняет текст паспорта и решает задачу № 1014.

## Основные теги и атрибуты

- `<header>`, `<main>`, `<footer>` делят страницу на крупные смысловые части.
- `<nav>` содержит ссылки навигации.
- `<h1>` — главный заголовок, `<h2>` — заголовок раздела.
- `<ul>` создаёт маркированный список, `<ol>` — нумерованный, `<li>` — элемент списка.
- `<a href="...">` создаёт ссылку. `target="_blank"` открывает новую вкладку,
  а `rel="noopener"` защищает исходную вкладку.
- `<img src="..." alt="...">` выводит изображение; `alt` описывает его словами.
- `id` даёт элементу уникальное имя, а `href="#id"` ведёт к нему как к закладке.
- `aria-current="page"` показывает текущий пункт меню программам доступности и CSS.

## Относительные пути и якорные ссылки

Путь `images/raincoat.jpg` считается от текущей папки проекта, поэтому работает и
локально, и в подпапке GitHub Pages. Путь `/images/raincoat.jpg` не использован,
потому что начальный `/` указывал бы на корень всего сайта GitHub.

Ссылка `catalog.html#raincoats` сначала открывает `catalog.html`, а затем прокручивает
страницу к элементу с `id="raincoats"`.

## Устройство таблицы

`<table>` создаёт таблицу, `<caption>` — её название, `<thead>` — строку заголовков,
`<tbody>` — основные строки, `<tr>` — строку, `<th>` — заголовочную ячейку, `<td>` —
обычную ячейку. Фон задан свойством `background-image` для всей таблицы, а белый
полупрозрачный фон ячеек сохраняет читаемость текста.

## Как работают формы

`<form>` объединяет поля. Атрибут `action="https://httpbin.org/get"` задаёт удалённый
адрес, а `method="get"` отправляет поля в строке запроса. Сервис httpbin не оформляет
заказ и не доставляет письмо — он только возвращает полученные значения для проверки.

- `name` — имя переменной, которое получает сервер;
- `value` — отправляемое или начальное значение;
- `required` запрещает отправку пустого обязательного поля;
- `label for="..."` связывается с полем по его `id`;
- `checked` выбирает начальное radio/checkbox;
- `selected` выбирает начальный пункт списка;
- `min`, `max`, `minlength` задают простые ограничения.

Тип `password` только скрывает символы на экране. Сам по себе он не шифрует данные.

## DOM и события

DOM — представление HTML-страницы в виде объектов. Команда
`document.getElementById('passport-surname')` находит элемент по `id`, а `textContent`
читает или меняет его текст.

`addEventListener('click', функция)` запускает функцию после клика. В проекте этот
способ используется для кнопок изменения фамилии и имени. Обработчик `input` у задачи
сбрасывает старый результат при изменении числа.

## Логика задачи № 1014

Выражение:

```text
(a <= c && b <= d) || (b <= c && a <= d)
```

Первая часть проверяет размещение без поворота. Вторая меняет стороны внутреннего
прямоугольника местами и проверяет поворот на 90°. Оператор `&&` означает «и» — должны
выполниться оба сравнения. Оператор `||` означает «или» — достаточно одного варианта.
Знак `<=` допускает размещение впритык.

## Возможные вопросы преподавателя

1. **Зачем нужен `<!DOCTYPE html>`?** Сообщает браузеру, что документ написан на HTML5.
2. **Почему указан `lang="ru"`?** Это язык страницы для браузера и программ чтения с экрана.
3. **Зачем нужен `meta viewport`?** Чтобы страница правильно масштабировалась на телефоне.
4. **Чем `id` отличается от `class`?** `id` уникален, а один `class` можно дать многим элементам.
5. **Что делает `aria-current="page"`?** Обозначает текущую страницу в меню.
6. **Почему пути к файлам относительные?** Они работают в подпапке репозитория GitHub Pages.
7. **Зачем изображению `alt`?** Он описывает картинку, если она не загрузилась или используется экранный диктор.
8. **Чем `<ol>` отличается от `<ul>`?** `<ol>` нумерует пункты, `<ul>` показывает маркеры.
9. **Зачем у поля одновременно `id` и `name`?** `id` связывает поле с подписью и JavaScript, `name` отправляется серверу.
10. **Что делает `required`?** Не позволяет браузеру отправить пустое обязательное поле.
11. **Почему форма открывает новую вкладку?** Чтобы увидеть ответ учебного сервера и не потерять страницу сайта.
12. **Что такое DOM?** Объектная модель HTML-документа, доступная JavaScript.
13. **Что делает `textContent`?** Читает или заменяет текст элемента.
14. **Почему после изменения чисел отправка блокируется?** Чтобы на сервер не ушёл результат от старых данных.
15. **Как учитывается поворот прямоугольника?** Стороны `a` и `b` меняются местами во второй проверке.
